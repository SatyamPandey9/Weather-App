# 🌤️ Weather App (Jetpack Compose + MVVM + Retrofit)

A simple and modern Weather Application built using **Kotlin**, **Jetpack Compose**, and **MVVM architecture**.  
The app fetches real-time weather data using **Retrofit** from an external API and displays it with a clean UI.

---

## 🚀 Features
- 🌍 Search weather by location  
- 🌡️ Shows current temperature, humidity, and condition  
- ☁️ Displays weather condition icons  
- ⚡ Built with **MVVM architecture**  
- 📡 Uses **Retrofit** for API calls  
- 🎨 Jetpack Compose for UI  

---

## 🛠️ Tech Stack
- **Language:** Kotlin  
- **UI:** Jetpack Compose  
- **Architecture:** MVVM (Model-View-ViewModel)  
- **Networking:** Retrofit  
- **Other:** Coroutines, LiveData/StateFlow
